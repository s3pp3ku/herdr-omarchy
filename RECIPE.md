# Omarchy

The Omarchy desktop, rebuilt inside Herdr: flat, square, bordered tiles floating over a wallpaper. The sidebar shows every space and agent with its live status, the top bar shows the AI quota of the agents on screen, and a side panel holds your files, Git changes and the full commit graph. Closed tabs reopen in place with their agents back in their own conversations. Omarchy's themes, wallpapers, theme switcher and keys come with it, and the palette, Settings, keybindings list and mod manager all share the same square look.

## What you see

Top to bottom, left to right. Sizes are logical px at zoom 1. Colors below are the default `tokyo-night` theme; every color is a theme name, so the other 22 themes recolor everything.

- **Top bar** (`topbar`, 30px, `chrome` `#16161e`, drags the window):
  - **Left** (weight 3; weight 1 under 1024px): a 2x2 grid menu icon in `accent` `#7aa2f7` (opens the palette), then three flat 30px buttons in `dim`: sidebar toggle, browser (a globe: `tab.new` named Browser running `herdr-browser view` through the person's shell, a blank browser tab in the space on screen) and search. No space numbers: the sidebar lists the spaces. After a `│` separator come the current space name, the focused terminal's folder when it differs, its branch and `@machine` when remote.
  - **AI usage** (weight 2.5; weight 2 under 1024px; content right-aligned, against the window buttons): one segment per agent provider visible in the current tab: the program icon, then each of its first two windows (5h and 7d for Claude and Codex) as its `dim` label, a 6px horizontal bar (70px wide alone, 48px for two, 32px for three or more) and its % ("5h ▬ 51%  7d ▬ 24%"). Segments are split by the bar's own `│` divider in `border`. Each Claude segment names its profile after the icon: the label `settings.json`'s optional `claude_labels` gives its folder (`{ "~/.claude": "Work" }`), else the organization in the profile's `.claude.json` (`~/.claude.json` for `~/.claude`, else `<dir>/.claude.json`) such as "Flexspring", "Personal" for a personal account's "<email>'s Organization", else the folder name after `.claude-`, capitalized. Each bar fills in its provider's brand color, taken from Herdr's program icons: Claude `#D97757`, Codex `#7A9DFF`, Copilot `#a371f7`. It turns amber `#ffb347` at 80% or more and red `#ff5d6c` at 95% or more. Agents without a usage API show "no usage API" in `dim`.
  - **Right** (90px, or 0 when the window has no buttons of its own): minimize, maximize/restore, close, as flat 30px square buttons. Close turns `blocked` on hover.
- **Desk** (row, 10px padding and 10px gaps, the theme's wallpaper from `backgrounds/omarchy/<theme>/` shows through):
  - **Sidebar** (243px column of three tiles, each `chrome` with a 2px `border` `#414868` frame; inside each tile there is 10px of top padding like the footer, a 26px header, then the list 6px below it and 10px from the sides; header text starts 18px in to line up with row text, and header buttons sit 10px from the right):
    - **Spaces** (weight 1): header "spaces 8" and a square `+`. Rows are 26px, each with a 16px square number badge. The active row's badge is `accent` with `accent_foreground` text, the row has an 18% foreground fill and a 2px `accent` bar on its left. Other badges are `dim` numbers in a 1px `border` square. A branch name appears only when it fits whole. A space with an agent working, needing input or done ends in a 6px square in that status color. Rows have no fill at rest, only on hover and when active. A hovered row (wide sidebar only) shows a 13px × that closes the space with `space.close`: Herdr asks first, except when the space has a working or blocked agent, where the first click turns the × red ("Click again to close it") and a second click within 3 seconds closes it with `confirmed: true`.
    - **Agents** (weight 1): header "agents 3", grouped "working 1", "idle 2". Rows are 26px with the program icon, the folder the agent is in now (its pane's live `cwd`, not the folder its space was started in), what the agent works on (its title, never just a program name like "Claude Code"), age, and a 7px square status dot. The focused row has an 18% fill and a 2px accent bar. A hovered row, sub-agents included, shows a × beside the pin that stops the agent with `terminal.kill`: idle or done ones on one click, working or blocked ones on a second click within 3 seconds after the × turns red. Under 230px wide the rows tighten their padding and drop the age, and the name takes whatever room is left.
    - **Footer** (136px): "Prefs", "Keys", "Mods" (layers icon, the mod manager) and "Add" rows (the full names, "Settings", "Keybindings", "Add machine", as tooltips) with 10px top and bottom padding and no fill until hovered.
  - **Work column**:
    - **Tab strip** (36px tile): flat 240px cells with 1px `border` dividers. Each cell shows the agents' program icons, then what they work on (session title, else folder such as `~`, else branch; a shell's bare terminal address like `t4c` never counts as a title), a status word and a spinner while working. Program names like "Claude Code" or "Codex" never appear: the icons carry them. The active tab has an 18% fill and no bottom bar. A tab's × shows when it's active or under the pointer, so any tab can be closed without selecting it first. A 36px `+` cell sits right after the last tab, and Files / Changes / Git toggles sit flush right. Every item in the strip is a full-height flat cell with a 1px `border` divider; the open panel's toggle gets the same fill as the active tab.
    - **Panes**: square, 2px `border` frame and 2px `accent` frame when focused, 10px gaps, 30px header (`omarchy-pane`) that shows the program icon and what it works on (its title, else the folder), never the program name, terminal padding 12px. Tab icons and pane header icons line up on the same left edge.
    - **Side panel** (475px, hidden until toggled): a stack of Files (`omarchy-files`, colored file-type icons and Git status colors), Changes (a stack `changes`: `changes-view` = `omarchy-changes` `{graph:"git-graph"}` with diff, Wrap and Graph header buttons, Fetch/Pull/Push/Stash/Pop row with ahead/behind counts, a branch list with `+ New branch…` (`git switch -c`), commit box and a solid `accent` Commit button; `git-graph` = `omarchy-changes` `{view:"graph", back:"changes-view"}`, the full commit graph with `← CHANGES` in its header, where Changes has its Graph button, and no title of its own). The file list and diff split at a draggable 8px gap (`shared("omarchy-changes.list")`, double-click fits the list again) and browser notes (`herdr-browser`).
- **Dialogs**: the palette (`ctrl-shift-p`, 660x450), Settings (`ctrl-,`, 970x690) Mods (`ctrl-shift-m`, 60% x 75%) and Themes (`super-ctrl-t`, 360x480) are square copies of Herdr's own screens. So are the go-to picker (search button, 640px popup), Add a machine (560px), notifications and the right-click menus: every corner square, no rounded badge or button.
- **Type**: CaskaydiaMono Nerd Font for terminals and UI. UI text is 11-13px, headings up to 16px.

## How it behaves

- **Agent status**: working shows the `working` `#e0af68` color, a pulsing square in the agents list and a spinner on the tab. Blocked (needs input) is `blocked` `#f7768e`, done is `done` `#9ece6a`, and idle is a hollow `dim` square. A tab's status is the most urgent of its agents.
- **Tabs with several agents**: the cell shows up to three distinct program icons side by side and the lead agent's work as its label. The tooltip lists each agent with its own status. A tab the person renamed keeps its name.
- **AI usage follows the screen**: it shows providers for the agents in the focused tab (focused pane first, zoom respected). With no agent in view it keeps the last list, dimmed. Clicking it opens a popup with every window and its reset time, in 12-hour time ("resets in 2h 10m, at 4:30 PM"). Each provider refreshes when it first appears, then every 5 minutes.
  - **Live providers**: Claude (5h and 7d, plus model-scoped weekly limits), Codex (ChatGPT plan 5h and 7d) and Copilot (monthly premium requests).
  - **Mapped**: Pi reuses those three when its configured provider is Anthropic, OpenAI Codex or GitHub Copilot. OpenCode/OpenAI can opt into Omarchy agents' Codex quota cache (`~/.local/state/omarchy/agents/usage/codex.json`); it shows Omarchy's ChatGPT subscription, without verifying that it matches OpenCode's account. The opt-in is absent by default. To enable it in an existing `layouts/omarchy.json`, add `"usage_source":"omarchy"` to the `ai-usage` block's `content.props`, keeping `compact:true`.
  - **Labelled only**: omp, devin, droid, kimi, kilo, hermes, qodercli, qwen, letta, cursor, mastracode, antigravity-cli and grok.
  - **Claude accounts**: when two Claude config directories exist (`~/.claude`, `~/.claude-personal`), the meter matches each terminal's `CLAUDE_CONFIG_DIR` to show the right account. An account with no login is hidden.
- **Clicks**: a space number selects the space; the menu icon opens the palette; search opens the picker; the sidebar toggle collapses the sidebar to a 44px rail and back. A double-click on a tab renames it, dragging reorders, and right-click opens the tab menu.
- **Side panel**: remembered per space. In a space that isn't a Git repo the Changes button is hidden and a remembered Changes panel stays closed.
- **Hover**: controls get an 8% foreground fill and a 1px border at 25% foreground alpha, after Omarchy's shell control tokens.

## Built from

- **Layout** `layouts/omarchy.json`: root `column` (`toast` `omarchy-toast`, `terminal_menu` `omarchy-menu`, theme `tokyo-night`, `font` and `ui_font` CaskaydiaMono Nerd Font, `titlebar: "none"`, background image cover, `terminal_padding` [12,12]).
  - `topbar` row: `bar-left` (`omarchy-bar` `{part:"left"}`), `ai-usage` (`omarchy-ai-usage` `{compact:true}`), `bar-right` (`omarchy-bar` `{part:"right"}`).
  - `desk` row: `sidebar` column (`spaces` → `omarchy-spaces`, `agents` → `omarchy-agents`, `sidebar-footer` → `omarchy-chrome` `{footer:true}`) and `work` column (`tabs` → `omarchy-tabs`; `work-body` row with `main` `{tab:"active"}`, whose pane header is `omarchy-pane`, and the `panel` column with stack `panel-body`: `files`, `changes` (stack: `changes-view`, `git-graph`), `browser-notes`).
- **Mods** (all in `mods/`):
  - `omarchy-bar`, `omarchy-ai-usage`: new. `omarchy-bar` also ties the wallpaper to the theme: on any theme change it sets the layout background to the theme's first wallpaper (`layout.set` through `herdr-app do`, since `run()` refuses an argument nested deeper than 16 levels and this layout is deeper), and its `next-wallpaper` command cycles the theme's wallpapers.
  - `omarchy-themes`: new. Theme switcher after Omarchy 4's: a full-window dialog (`frame: "none"`) over the window dimmed to 80% black. Omarchy's desktop preview of each theme (`previews/<theme>.webp`, 800px WebP from upstream `themes/<theme>/preview.png`): the chosen one at half the window width (16:9) with a 3px `accent` frame, and up to six neighbours each side as 64px strips cropped from their previews at 88% height, solid and shaded darker with distance. Below, the name in 30px semibold title case and a `current` tag. ←/→ (wrapping) choose, a strip jumps to its theme, Enter or a click on the middle applies, Esc closes. Only themes with a preview are listed; there is no perspective tilt (GPUI has no transforms). Picking a light theme sets `settings.json` `appearance` to `light` (a dark one to `dark`), since a light theme only shows in light mode.
  - `omarchy-keys`: new. Every binding from `keys()`, grouped This layout / Everywhere / In a terminal (other sections by name), key chips and the raw action; a filter box; global keys the layout also binds read `overridden here`. Inside each section, keys are grouped by type (Spaces, Tabs, Panes, Agents, Terminal, Dialogs, Look), each row with a plain-English label ("Focus pane left") and the raw action small and `dim` on the right; numbered runs fold into one row ("Go to tab 1…9"). Section and type headings fold on click (▾/▸ chevron and key count, remembered in `localStorage`); typing a filter opens them all and also matches labels and group names. The shown layout's own keys come first as one `accent` block (2px left bar, 5% tint, "THIS LAYOUT · CAME WITH OMARCHY" and a count, `accent` key chips). Opened with `super-k` (Omarchy's key) or the footer's Keybindings row (footer 136px for its four rows).
  - `omarchy-chrome`, `omarchy-spaces`, `omarchy-agents`: clones of Herdr's `workspace-chrome`, `spaces` and `agents`.
  - `omarchy-palette`, `omarchy-settings`: copies of Herdr's `frame/palette` and `frame/settings`, with `rounded(0)`.
  - `omarchy-toast`, `omarchy-menu`, `omarchy-picker`, `omarchy-machine-add`: clones of Herdr's `toast`, `menu`, `picker` and `machine-add` (`cloned_from` in each `mod.json`), restyled with square corners and theme colors only, same behavior. The layout root sets `"toast": "omarchy-toast"` and `"terminal_menu": "omarchy-menu"`; the bar and sidebar footer open the picker and the add-machine dialog (`mod.open`), and the space and tab menus open `omarchy-menu`. The picker's space badges are drawn like the sidebar's (accent when active, `dim` in a 1px `border` square otherwise) instead of Herdr's per-space colors.
  - `omarchy-mod-manager`: install, update, remove and AI-edit mods, Marketplace tab. Drawn as a full-window dialog (`frame: "none"`) over the window dimmed to 70% black: one panel (at most 1180x780, zoom-aware) with a 2px `accent` border; a 28px "Mods" title, uppercase INSTALLED / MARKETPLACE tabs with count badges and a 2px `accent` underline; 56px rows with a 34px two-letter monogram tile tinted by kind (installed `done`, local `accent`, built-in `muted`, update `blocked`), the name over a `dim` kind · folder line, and an uppercase status chip (solid "↑ UPDATE" when one is out); a details card with a 56px tile, the name at 20px, uppercase label/value facts and full-width buttons with keycaps; key hints as chips on a `raised` footer strip.
  - `omarchy-tabs`: based on RofieSagara/herdr-auto-tabs (Apache-2.0, see its NOTICE). It also keeps the last 10 closed tabs (`shared("omarchy-tabs.closed")`, across restarts) for `ctrl-alt-shift-t` (`omarchy-tabs.reopen`). While a tab lives, a `/proc` scan (`reopen.js` `SCAN`, run when panes, folders, programs or statuses change) finds each Claude or Codex process by its `HC_TERMINAL_ID`: Claude resumes with `--resume <sessionId>` from `<config dir>/sessions/<pid>.json`, in its own `CLAUDE_CONFIG_DIR` and with its own flags (`--continue` without a session file); Codex with `codex resume <id>` from the rollout file it has open (fresh `codex` before its first message); other agents start again; shells come back in their folder. Reopen makes the tab in its space (else the current one) with its name, the first pane by `tab.new`, the rest `terminal.open` to the right; each agent runs as `$SHELL -lc '<cmd>; exec $SHELL'` so the pane stays when it exits. Splits come back side by side, not in their old arrangement. It also holds `omarchy-tabs.tab-prev/next` (`jump.js`): the previous or next tab in the space with a working or blocked agent, or simply the previous or next tab when no other one has one.
  - `omarchy-pane`, `herdr-browser`: pane header and browser notes, which pair with the herdr-browser helper.
  - `omarchy-files`, `omarchy-changes`: colored Files and Changes panels; Charmed icons, see `CHARMED-LICENSE.md`.
  - `omarchy-changes/graph/`: the commit graph, part of `omarchy-changes` (its `main.js` hands `{view:"graph"}` and the graph's popups, `{role}`, to `graph/main.js`). From rabeeh-ta/herdr-git-graph v0.3.0 (MIT, see its `LICENSE`), restyled: every corner square but the commit dots, no outer border or radius (the panel draws the frame), one border (under the header), branch labels as tinted fills with clear 1px borders (the hit test counts them), no title (a `MANYGIT` 11px `muted` header for a folder of repos), shared keys `omarchy-changes.graph.*`, and the upstream update check off. Its tests are `tests/omarchy-changes-graph-*.test.mjs`. It lives inside Changes, so the tab strip has no Graph button (that button shows only when `panel-body` has a direct `graph` child). The diff Wrap choice is `shared("omarchy-changes.wrap")`; wrapped diffs drop the virtual list (rows vary in height; diffs are capped at 1,500 lines).
- **Themes**: `themes/*.json` are the 23 Omarchy themes rendered through Omarchy's own `default/themed/herdr-app.json.tpl`, plus `canvas`/`chrome` = `dark_background` and `border` = `muted`.
- **Keys** (`keys.json`, section `layout:omarchy`): `ctrl-shift-p` → `mod.open:omarchy-palette`, `ctrl-,` → `mod.open:omarchy-settings`, `ctrl-shift-m` → `mod.open:omarchy-mod-manager`, `super-ctrl-space` and `super-ctrl-w` → `omarchy-bar.next-wallpaper`, `super-ctrl-shift-space` and `super-ctrl-t` → `mod.open:omarchy-themes` (Omarchy's own keys). Also Omarchy's Herdr keymap (`config/herdr/config.toml` upstream) where GNOME leaves the key free: `alt-1..9` → `tab.select`, `alt-left/right` → `tab.prev/next`, `alt-up/down` → `space.prev/next`, `alt-shift-up/down` → `agent.prev/next` (every agent, any status), `alt-shift-left/right` → `omarchy-tabs.tab-prev/next` (tabs with a running agent), `alt-enter` / `alt-shift-enter` → `pane.split` right / down; and Omarchy desktop keys: `super-return` → `terminal.open`, `super-w` → `pane.close`, `super-f` → `pane.zoom`, `super-c/v` → `terminal.copy/paste`, `super-alt-space` → the palette, `super-shift-space` → `layout.toggle:topbar`. Skipped for GNOME: the `ctrl-space` prefix (IBus), `alt-esc`, `ctrl-alt(-shift)-arrows`, `super-1..9`, `super-arrows`, `super-tab`.
- **Shipped mods it still opens**: `new-menu` (the tab strip's `+`) and `worktree` (from `omarchy-menu`). Nothing else refers to Herdr's shipped mods. Icons that came from them (`pane`, `terminals-bar`, `workspace-chrome`, `files`, `changes`) are copied into the mod that draws them, from Herdr's Apache-2.0 app (see `omarchy-tabs/NOTICE`).
- **Pane movement**: merge `ctrl-left/right/up/down` → `pane.go:left/right/up/down` into both `layout:omarchy` and `terminal` from `keys.json`. Terminal bindings win over layout bindings, so these apply in terminals across layouts and replace Ctrl+Left/Right word movement.
- **Herdr API it uses**: `spaces`, `agents`, `panes`, `terminals`, `focused`, `layout`, `theme`, `window`, `shared`/`setShared`, `openOverlay`, `run` (`space.select`, `tab.select`, `tab.rename`, `tab.move`, `tab.close`, `layout.show`/`hide`/`select`/`resize`, `mod.open`, `window.*`).
- **Art**: `backgrounds/omarchy/<theme>/` holds every Omarchy wallpaper of each theme (MIT, see `LICENSE-omarchy`), WebP at quality 80, at most 1920x1080 cover. The default is Tokyo Night's `1-winding-road.webp`.

## Watch out

- **Reopen closed tab**: exact pane trees and sizes need `python3` and `hc connect`. Without them, reopening uses a basic row of panes. Agent session detection reads Linux `/proc` and local session files.
- **Network and programs**: check these before installing.
  - `omarchy-ai-usage` reads login files only for direct provider sources and never stores tokens:
    - `~/.claude*/.credentials.json`
    - `~/.codex/auth.json`
    - `~/.config/github-copilot/*.json`
    - `~/.pi/agent/auth.json`
    - `~/.local/share/opencode/auth.json` (OpenCode's direct route when the layout opt-in is absent or its selected provider is not OpenAI)
  - The OpenCode/OpenAI layout opt-in reads only Omarchy agents' `~/.local/state/omarchy/agents/usage/codex.json`; the cache must be `ready`, not stale and no older than 12 minutes. It does not refresh credentials or call a quota endpoint. The source is Omarchy's subscription; its account is not verified against OpenCode.
  - Direct usage calls only the providers' own hosts: `api.anthropic.com`, `chatgpt.com`, `api.github.com`. On Linux it reads `/proc/*/environ` to match each terminal to its Claude config directory.
  - `omarchy-spaces` and `omarchy-changes` run `git`.
  - The graph in `omarchy-changes` runs `git`, `find` and `env` (Manygit's fetch-all), and reads files in the repo for diffs.
  - `omarchy-pane` runs `xdg-open` (Linux), `open` (macOS) or `explorer` (Windows) to open links. On Linux its browser toolbar also runs `google-chrome` or `chromium` as an app window: for the page (`ctrl-alt-o`, key command `omarchy-pane.dev`) and for DevTools on the page the pane shows (`ctrl-alt-i`, `omarchy-pane.inspect`). It watches the folder of a local page and reloads the page when an HTML, CSS, JS, JSON, image or Markdown file in it is saved, except while annotating and for pages directly in `/tmp`. The DevTools button and its red error count need the helper patch in `patches/herdr-browser.patch`, applied with `sh patches/apply-herdr-browser.sh` (safe to run twice; run it again after a Herdr update); without it the button stays disabled.
  - `omarchy-bar` starts `herdr-browser view` through the person's shell (`$SHELL -lic`) for its browser button.
  - `herdr-browser` talks to the local herdr-browser helper (`~/.local/share/herdr-browser`).
  - `omarchy-mod-manager` runs `git`, `gh` (its Marketplace searches GitHub repos tagged `herdr-mod` and `herdr-layout`) and `herdr-app check`.
- **Herdr screen copies**: the palette, Settings, toast, menu, picker and add-machine copies won't follow Herdr updates to its own screens and mods. Re-copy `frame/palette`, `frame/settings` and the shipped `toast`, `menu`, `picker` and `machine-add` and reapply `rounded(0)` after a big update.
- **Fixed widths**: a fresh build tends to get these wrong.
  - `bar-right` is as wide as its buttons, so the usage block ends against them; `bar-left` takes the rest.
  - The usage meter fits about three providers before it truncates.
  - The tab strip assumes 240px cells.
- **Claude account matching**: it is Linux-only and cached per terminal. Elsewhere, both logged-in accounts show.
- **Pi and OpenCode**: they are read from their configured default provider, not the model a running session switched to.
- **Theme names**: if Omarchy itself is installed, its theme switcher writes `themes/omarchy.json` for Herdr. That theme works with this layout, but the layout's default stays `tokyo-night`.
- **Fonts**: CaskaydiaMono Nerd Font must be installed. Without it Herdr falls back to JetBrains Mono, and the layout still works.

## Done when

- `npm test` passes (mod manager core, file icons, diff and Git row) and `herdr-app check mods/<name>` passes for every mod under `mods/`, and `herdr-app status` shows `"errors": []` with `layout: "omarchy"`.
- The top bar is one 30px row: grid icon, sidebar, browser and search buttons, the space name, then usage segments right-aligned with a horizontal bar each, and the three window buttons. Nothing is cut off at 1920px wide.
- Spaces, agents and the footer are three separate bordered tiles with the wallpaper visible between them.
- A tab with a Codex and a Claude pane shows both icons and a session title, never "Codex" or "Claude Code", and the usage meter shows a Claude and a Codex segment.
- In a non-Git space the Changes button is missing, and in a Git repo it is back.
- `ctrl-shift-p`, `ctrl-,` and `ctrl-shift-m` open square dialogs, and picking `nord` in Settings recolors every block.
